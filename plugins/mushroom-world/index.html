Mushroom World

universal buildphysical modelmodel signalmodel as modulator

Every mushroom plugin in one: a proposal for how the whole collection could go into SynthLand Explorer as a single plugin. Choose a species and the size of simulator it was grown in. Two voices, each one of eight instruments, played from the keys or by one of six composers. An atmosphere underneath, an effect built from the same network, and a console. Three world controls, growth, wetness and warmth, move every part at once.

Press Start audio, then play the keys on screen, type A W S E D F T G Y H U J K, or use a MIDI keyboard. Click a part on the left to see its picture and its controls. Drag a knob up and down; double-click it to put it back. The panel is a fixed 1180 by 700, as a SynthLand skin is, and is scaled here to fit the page.

What is inside

How this is built for SynthLand

The panel is a SynthLand skin

The folder skin/ holds index.html, skin.css and skin.js, a fixed size, theme colours as --sl-* tokens, system fonts, no network use, and it talks only to window.synthland. Here bridge.js is a web stand-in for the host; in SynthLand the host supplies its own.

One parameter table, generated

manifest.json is in the shape of a SynthLand manifest, with every parameter in real units and ids as group.name. It is written by tools/build-world.js from the separate plugins' own declarations, so the combined plugin cannot drift from them.

The sound is the plugins' own code

The engine here runs the same JavaScript as the separate plugin pages. For SynthLand it would be ported to a C++ core. The plan, the options and the costs are in docs/SYNTHEXPLORER.md.

What is assumed

Everything each separate plugin assumes is assumed here too, and each plugin's own page lists it. The console is a small stand-in for SynthLand's Stem Console. The 25 invented species are marked as invented wherever they appear. Nobody has listened to this: it has been checked by rendering every part offline and by loading the page, not by ear.
