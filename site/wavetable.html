A morphing wavetable cut from a network's electrical activity. Each frame is one cycle of the voltage between two electrodes, and the 64 frames run from the start of the network's growth to its end. Play it here, or save it for a wavetable synthesiser.

What this is

The engine's electrical model is a set of coupled oscillators along the hyphae, with the growing tips running slightly fast. Two electrodes on the network drift in and out of step as it grows, so the voltage between them changes shape. One cycle is cut out at each of 64 stages of growth, closed into a loop, and reduced to its first 512 harmonics. Scanning the table replays that change of shape; the note you play sets the pitch.

This is not physical modelling, and it is kept apart from the listening page for that reason: the model's voltage is used directly as an oscillator's shape. The cycle really lasts minutes to hours, and the spike recordings behind the model are disputed.

Using the files

The WAV is 64 frames of 2,048 samples end to end, with the marker that Serum and Vital read for the frame size. In Ableton's Wavetable, drop it on an oscillator and set the import to 2,048 samples if it asks. The JSON holds each frame as 512 harmonic amplitudes and phases, the same shape SynthLand's wavetable engine stores its own tables in; it would still need importing there.
